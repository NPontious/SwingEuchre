A Classic Card Game, Reimagined in Java.

SwingEuchre is a fully-featured desktop version of the beloved trick-taking card game, complete with a clean graphical interface and smart AI players.

Game Rules

  • Each player is dealt six cards.
  • Bidding proceeds clockwise, starting from the player to the left of the dealer.
  • The highest bidder chooses the trump suit for the round.
  • Players must follow the lead suit if they can.
  • The player with the highest-value card wins the trick and leads the next one.
  • The game continues until one team reaches a score of 32 points.

Useful Terms

Trump: The suit chosen by the high bidder, which outranks all other suits.

Trick: A round of play where each player plays one card.

Bar: The Jack of the trump suit (Right Bar) and the other Jack of the same color (Left Bar) are the two most powerful cards.

Get Started in Minutes

Ready to play? Since this is a Java desktop application, you'll need to run it on your computer. Follow these simple steps:

  1. Download Java: Make sure you have the Java Runtime Environment (JRE) installed.
  2. Download the Game: Grab the latest `.jar` file from the releases page.
  3. Run the Game: Simply double-click the downloaded file to start playing!
